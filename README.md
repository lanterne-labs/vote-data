# vote-data

The public mirror of tartuffe.me's vote ledger (isoloir, origin
`tartuffe.me/vote-log`): the signed checkpoints, every log entry, the
registry and ballot trees, the results with their inclusion proofs, the
OpenTimestamps stamps, and the circuits voters prove with. Written by the
ingest; read by browsers through jsDelivr by commit.

Recount it yourself: https://github.com/lanterne-labs/isoloir (`isoloir audit`).
